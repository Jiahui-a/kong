# Cascon 芯片测试文件夹同步工具

将各同事本地 Cascon 项目中的芯片测试文件夹，按 `database.xlsx` 映射关系**复制**到公盘 `database` 目录。重命名**仅发生在公盘副本上**，本地原始文件夹不会被修改。

## database.xlsx 列规则

| 列 | 含义 |
|----|------|
| 第 1 列 | 可选序号 |
| **第 2 列** | **料号**（合并区内容会展开到每行；未合并且为空则空，不继承上一行） |
| **第 3 列** | **型号**（合并区内容会展开到每行；未合并且为空则空，不继承上一行） |
| 第 4 列起 | **项目名**（表头），单元格值为该料号在该项目中的**位号** |

示例：

| 序号 | 料号 | 型号 | ProjectA | ProjectB |
|------|------|------|----------|----------|
| 1 | C12345-001 | STM32F103C8T6 | U1 | U5 |
| 2 | C12345-002 | GD32F303CCT6 | U2 | |

同一料号在不同项目中位号可以不同（如 ProjectA 为 `U1`，ProjectB 为 `U5`）。

**料号继承**：Excel 中常见合并单元格写法，后续行只填位号。工具会先**展开合并单元格**再读取——合并区内每一行都会得到合并单元格的内容（不会为空）。只有未合并且单元格本身为空时，料号才为空（不会再去找上一行非空料号）。**型号不向上继承**：单元格为空则型号为空，仅当当前单元格（含合并单元格）有值时才使用。某个项目名下的位号为空时跳过该项目内容；仅当**所有项目列均为空**时才跳过该行。

| 序号 | 料号 | 型号 | ProjectA |
|------|------|------|----------|
| 1 | C12345-001（合并至下行） | STM32F103C8T6 | U1 |
| 2 | （合并后读到 C12345-001） | | U2 |

上例料号列 B2:B3 为合并单元格时，第 2 行展开后读到料号 `C12345-001`（即合并区内容）；型号列未合并则为空（不继承），ProjectA 位号为 `U2`。若型号列也是合并单元格，则第 2 行同样读到合并区内的型号。若料号**未合并**且单元格为空，该行料号才保持为空。

**同一项目、同一料号对应多个位号**时，可在项目列单元格内用**顿号（、）**分隔，也支持换行、逗号、分号：

```text
U1、U2、U3
```

工具会将每个位号分别用于文件夹匹配。

## 目录遍历规则

```text
同事电脑 Cascon 工作区/
├── ProjectA/              ← 文件夹名须与 database 项目列表头一致
│   ├── [U1]/              ← 芯片测试项文件夹（下一级）
│   ├── [STM32F103C8T6]/
│   └── [STM32F103C8T6 U1]/
└── ProjectB/
    └── [U5]/
```

1. 在 `--source` 指定的工作区中，查找名称与 database 项目列匹配的**项目文件夹**
2. 在每个项目文件夹的**直接子目录**中，查找芯片测试项文件夹
3. 芯片文件夹名通常含 `[]` 包裹的内容；`[]` 后可有后缀，如 `[Car_Interface]_02`，工具只取括号内内容匹配

`--source` 可以是：
- **工作区根目录**（自动遍历其子文件夹中与 database 项目列同名的目录）
- **单个项目目录**（目录名本身即为项目名）

## 文件夹查找与匹配规则

在**项目上下文**中匹配（位号取自该项目对应列，不会跨项目混淆）。

### 命名预处理

1. 提取文件夹名中 `[]` 内的内容；`[]` 后可有后缀，如 `[Car_Interface]_02` → `Car_Interface`
2. 比对时忽略大小写，忽略空格、`_`、`-` 差异

### 匹配规则

文件夹名中**只要有一个内容**与料号、位号或型号匹配即可（按优先级）：

| 优先级 | 规则 | 示例 |
|--------|------|------|
| 1 | **位号** | `[U1]`、`[U1]_02` |
| 2 | **料号** | `[C12345-001]` |
| 3 | **型号** | `[STM32F103C8T6]`、`[Car_Interface]_02` |
| 4 | **组合名** | `[STM32F103C8T6 U1]`、`[U1-STM32F103C8T6]` |
| 5 | **部分令牌命中** | 文件夹令牌中包含位号/料号/型号之一 |

### 约束条件

- 只在 database 中**该项目列有位号**的记录里查找
- 若同一规则匹配到多条记录，视为歧义，不自动同步（报告错误）
- 公盘目标名由非空的**型号、料号、位号**组成，如 `[STM32F103C8T6 C12345-001 U1]`；型号或位号为空时自动省略

## 安装

```bash
cd cascon-database-sync
pip install -r requirements.txt
```

生成 database 模板：

```bash
python scripts/create_template.py
```

## 使用方法

### 图形界面（推荐）

```bash
# 无参数启动，弹出操作窗口
python -m cascon_sync
```

界面上可手动选择：
- **database.xlsx**（文件）
- **Cascon 源目录**（可添加多个工作区或项目文件夹）
- **公盘输出目录**
- 可选 JSON 报告路径、预览模式、覆盖选项

### 打包 Windows exe

在 **Windows** 电脑上执行：

```bash
pip install -r requirements.txt
pip install pyinstaller
python scripts/build_exe.py
```

或：

```bash
pyinstaller CasconSync.spec
```

生成 `dist/CasconSync.exe`。双击即可弹出操作界面，无需安装 Python。

### 命令行

```bash
# 预览（推荐先执行）
python -m cascon_sync \
  --database ./database.xlsx \
  --source "D:\Cascon" \
  --output "Z:\database" \
  --dry-run

# 正式同步
python -m cascon_sync \
  -d ./database.xlsx \
  -s "D:\Cascon" \
  -o "Z:\database"
```

有命令行参数时走 CLI；无参数时启动图形界面。
## 重命名示例

**本地（不变）：**

```text
D:\Cascon\ProjectA\[U1]\
  [U1]\
  [U1].xlsx
```

**公盘（重命名）：**

```text
Z:\database\[STM32F103C8T6 C12345-001 U1]\
  [STM32F103C8T6 C12345-001 U1]\
  [STM32F103C8T6 C12345-001 U1].xlsx
```

## 项目结构

```text
cascon-database-sync/
├── cascon_sync/
│   ├── database.py     # 读取 database.xlsx（第2列料号、第3列型号、项目列位号）
│   ├── matcher.py      # 项目上下文下的文件夹匹配规则
│   ├── sync.py         # 复制到公盘并重命名
│   ├── cli.py          # 命令行入口
│   └── gui.py          # 图形操作界面（可选打包为 exe）
├── scripts/
│   ├── create_template.py
│   └── build_exe.py    # 打包 CasconSync.exe
├── CasconSync.spec
├── templates/
├── tests/
└── README.md
```
