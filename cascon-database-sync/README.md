# Cascon 芯片测试文件夹同步工具

将各同事本地 Cascon 项目中的芯片测试文件夹，按 `database.xlsx` 映射关系**复制**到公盘 `database` 目录。重命名**仅发生在公盘副本上**，本地原始文件夹不会被修改。

## database.xlsx 列规则

| 列 | 含义 |
|----|------|
| 第 1 列 | 可选序号 |
| **第 2 列** | **料号**（可为空；为空时向上继承最近非空料号） |
| **第 3 列** | **型号**（可为空；为空时向上继承最近非空型号） |
| 第 4 列起 | **项目名**（表头），单元格值为该料号在该项目中的**位号** |

示例：

| 序号 | 料号 | 型号 | ProjectA | ProjectB |
|------|------|------|----------|----------|
| 1 | C12345-001 | STM32F103C8T6 | U1 | U5 |
| 2 | C12345-002 | GD32F303CCT6 | U2 | |

同一料号在不同项目中位号可以不同（如 ProjectA 为 `U1`，ProjectB 为 `U5`）。

**料号/型号继承**：Excel 中常见合并单元格写法，后续行只填位号。若某行料号为空，自动向上查找最近非空料号；型号同理。仅当**所有项目列均为空**时才跳过该行。

| 序号 | 料号 | 型号 | ProjectA |
|------|------|------|----------|
| 1 | C12345-001 | STM32F103C8T6 | U1 |
| 2 | | | U2 |

上例第 2 行会继承 `C12345-001` / `STM32F103C8T6`，ProjectA 位号为 `U1`、`U2`。

**同一项目、同一料号对应多个位号**时，可在项目列单元格内**换行**填写，也支持逗号、分号分隔：

```text
U1
U2
U3
```

工具会将每个位号分别用于文件夹匹配。

## 目录遍历规则

```text
同事电脑 Cascon 工作区/
├── ProjectA/              ← 文件夹名须与 database 项目列表头一致
│   ├── [U1]/              ← 芯片测试项文件夹（下一级）
│   ├── [STM32F103C8T6]/
│   └── [STM32F103C8T6 U1]/
└── ProjectB/
    └── [U5]/
```

1. 在 `--source` 指定的工作区中，查找名称与 database 项目列匹配的**项目文件夹**
2. 在每个项目文件夹的**直接子目录**中，查找芯片测试项文件夹
3. 芯片文件夹名通常被 `[]` 包裹，工具会自动去掉外层方括号再匹配

`--source` 可以是：
- **工作区根目录**（自动遍历其子文件夹中与 database 项目列同名的目录）
- **单个项目目录**（目录名本身即为项目名）

## 文件夹查找与匹配规则

在**项目上下文**中匹配（位号取自该项目对应列，不会跨项目混淆）。

### 命名预处理

1. 去掉文件夹名外层 `[]`，如 `[U1]` → `U1`
2. 比对时忽略大小写，忽略空格、`_`、`-` 差异

### 匹配优先级（从高到低）

| 优先级 | 规则 | 示例（ProjectA 位号为 U1，型号 STM32F103C8T6） |
|--------|------|------------------------------------------------|
| 1 | **位号精确匹配** | `[U1]` |
| 2 | **型号+位号组合** | `[STM32F103C8T6 U1]`、`[U1 STM32F103C8T6]`、`[U1-STM32F103C8T6]` |
| 3 | **令牌集合匹配** | 组合名分隔符不同，但包含的型号/位号令牌相同 |
| 4 | **型号精确匹配** | `[STM32F103C8T6]`（且该料号在本项目有位号） |

### 约束条件

- 只在 database 中**该项目列有位号**的记录里查找
- 若同一规则匹配到多条记录，视为歧义，不自动同步（报告错误）
- 公盘目标名由非空的**型号、料号、位号**组成，如 `[STM32F103C8T6 C12345-001 U1]`；型号或位号为空时自动省略

## 安装

```bash
cd cascon-database-sync
pip install -r requirements.txt
```

生成 database 模板：

```bash
python scripts/create_template.py
```

## 使用方法

```bash
# 预览（推荐先执行）
python -m cascon_sync \
  --database ./database.xlsx \
  --source "D:\Cascon" \
  --output "Z:\database" \
  --dry-run

# 正式同步
python -m cascon_sync \
  -d ./database.xlsx \
  -s "D:\Cascon" \
  -o "Z:\database"
```

## 重命名示例

**本地（不变）：**

```text
D:\Cascon\ProjectA\[U1]\
  [U1]\
  [U1].xlsx
```

**公盘（重命名）：**

```text
Z:\database\[STM32F103C8T6 C12345-001 U1]\
  [STM32F103C8T6 C12345-001 U1]\
  [STM32F103C8T6 C12345-001 U1].xlsx
```
